# Deployment lockfile — fully pinned, including transitive dependencies.
#
# `pyproject.toml` declares the direct dependencies and their intended ranges.
# This file is the exact resolved set the deployment installs, so two deploys
# of the same commit install byte-identical dependencies. Railway installs from
# this file; it is the reason a rebuild cannot silently pick up a new Starlette.
#
# Regenerate after changing pyproject.toml:
#   python -m venv /tmp/lock && /tmp/lock/bin/pip install -e . \
#     && /tmp/lock/bin/pip freeze --exclude-editable > requirements.txt
# then re-add this header, and re-run pytest and mypy against the new set.
#
# Deliberately excluded: the `local-reranker` extra (sentence-transformers,
# torch, transformers). That path is the zero-cost development reranker and the
# production startup check rejects it. Keeping it out of the deployment image
# removes roughly a gigabyte of wheels the deployed service never imports.
